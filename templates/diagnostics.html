How CodeMender Solves This

The Vulnerability: In app.py: diagnostics_view(), user input from request.form.get("host") is passed directly into a shell command using subprocess.run(cmd, shell=True): 

cmd = f"ping -c 2 {target_host}"
proc = subprocess.run(cmd, shell=True, capture_output=True, text=True)

CodeMender Workflow: cm find flags CWE-78 command injection because shell=True is invoked with untrusted variables. cm verify executes a proof-of-concept payload inside CodeMender's isolated OS sandbox (`exebox`) to confirm execution without touching host assets. cm fix replaces shell=True with argument array execution (e.g. subprocess.run(["ping", "-c", "2", target_host], shell=False)) and adds defensive IP/hostname regex validation, ensuring malicious shell operators like ; or | are never interpreted by the system shell.
